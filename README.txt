THE CURSED GARAGE
Live game: https://wikky1984.github.io/halloween2026/

Files
- index.html: game screens
- style.css: responsive design and reduced-motion support
- game.js: game logic and optional synthesized audio
- icon.svg: favicon

Operation
The game is hosted by GitHub Pages from the main branch and repository root. Visitors need no installation, login, or personal information. Sound is ON by default but begins only when the visitor taps ENTER, as mobile browsers require. The SOUND button turns it off at any point. Quiet ambience and heartbeats build tension; all effects are synthesized in the browser at modest levels. The seal counts only taps made while it glows green. With reduced motion enabled, the timing challenge is removed. The coffin, pumpkin, old door, ghost, icon, garage scene, poster graphics, and sound effects were created for this project. The character art is lightweight local SVG. There are no stock assets, external assets, or analytics, and there are no strobes or gore.

If the game does not load, check GitHub Settings > Pages for a successful deployment, then confirm index.html, style.css, game.js, and icon.svg are in the root of main. If audio does not play, confirm SOUND ON, tap ENTER, and check the phone volume and silent mode. If the QR is difficult to scan outdoors, add steady light to the poster without glare and test from several distances.

Before Halloween, scan the printed QR with an iPhone and an Android phone. Play all three choices, with sound on and off, and check the result and replay buttons.
